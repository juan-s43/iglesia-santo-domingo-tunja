# Sitio web de la Iglesia de Santo Domingo de Tunja

Proyecto integrador de Diseño Web (proyecto académico, no oficial).
Integrantes del grupo: **por completar**

## Cómo abrirlo
1. Descomprime el .zip.
2. Haz doble clic en `index.html`. Necesitas internet para que cargue Bootstrap.

## Estructura
- `index.html`, `la-iglesia.html`, `patrimonio.html`, `galeria.html`, `actualidad.html`, `visita-contacto.html`, `museo-virtual.html`: las 7 páginas.
- `css/estilos.css`: estilos propios (paleta, componentes esquemórficos).
- `js/`: `libro.js` (libro interactivo), `patrimonio.js` (filtros), `galeria.js` (ampliar fotos), `formulario.js` (validación).
- `img/`: fotografías (autores y licencias en cada página).

## Librerías usadas
| Librería | Versión | Para qué se usó |
|---|---|---|
